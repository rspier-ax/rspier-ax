## About

Senior Software Engineer building and modernizing software professionally since 2018.

My background combines frontend architecture, full-stack product delivery, backend integrations, platform modernization, and technical leadership. I have worked across enterprise applications, customer-facing products, internal platforms, automation, authentication, auditability, and real-time workflows.

My experience includes Carnegie Learning, Computing System Innovations, ADP, and Dell Technologies, working with distributed teams across Brazil and the United States.

## What I’ve built and contributed to

* Led frontend architecture and modernization across multiple enterprise portals using Angular, Nx, NgRx, shared libraries, and reusable component patterns.
* Built responsive, accessible, API-driven applications for customers, internal users, and operational teams.
* Reduced cross-team code duplication through modularization and shared application foundations.
* Modernized legacy Angular platforms to newer Angular versions, creating a safer foundation for continued product development.
* Designed reusable component libraries and UI standards adopted across four product areas.
* Developed backend services, REST APIs, integrations, authentication flows, audit logging, messaging, and automation.
* Built internal platforms and operational workflows using TypeScript, React, Angular, Next.js, Node.js, Java, Spring Boot, C#/.NET, PowerShell, Python, and SQL.
* Established testing, CI/CD, code quality, documentation, and frontend architecture practices across active workstreams.
* Mentored engineers and contributed to architecture decisions, technical planning, code reviews, and delivery across distributed teams.
* Worked closely with Product, Design, Support, and Engineering to turn complex requirements into maintainable software.
